# 历史源码

这些目录用于说明基础能力如何演进到当前版本，不参与默认构建。当前入口是仓库根目录 readme.md 和 build/reproduce.py。历史目录中的脚本可能依赖当时的文件布局、数据和工具环境；不能将仅保留源码误写成所有历史包均已在当前布局重新验证。

camera_trial 未形成稳定实时采集证据，不纳入正式功能。该目录不公开厂家寄存器初始化表，不提供可直接承诺可用的摄像头上板包。video_baseline 是本轮性能对照所使用的旧视频架构；其已测结果在 build/reports/baseline 与 board/results/paired_baseline。

index.json 记录历史文件原始哈希和公开副本哈希。私有路径清理与旧编码转换仅发生在历史公开副本，未改动本机原项目。
