# DMA 与 Overlay 排错

| 现象 | 首先确认 | 失败后处理 |
|---|---|---|
| 文件不存在或 SHA-256 不一致 | bit、hwh、manifest 是否同一轮构建 | 停止加载，恢复配套文件 |
| HWH 没有指定 IP | 实例名、层次路径和配置文件 | 修正配置，不能忽略缺失 IP |
| 长度检查失败 | shape、dtype、实际 nbytes、C_SG_LENGTH_WIDTH | 按硬件协议修正长度；不要截断输入伪造通过 |
| S2MM 一直等待 | 接收是否先启动，是否发出正确 TLAST | 保存 TX/RX 状态，复位 DMA 后再试 |
| 输出像素错位 | 字节顺序、每字像素数、TKEEP、边界和流水线延迟 | 保存失败帧，对照参考与仿真 |
| 连续帧出现旧数据 | 缓存 flush/invalidate、帧号和双缓冲所有权 | 先小帧复测，再恢复连续运行 |
| DDR 输出被覆盖 | CPU 是否修改接收缓冲而未 flush | 在 DMA 写前 clean，完成后 invalidate |
| 超时后无法复用 | DMA reset 是否完成、通道是否静止 | 不释放仍可能被设备访问的内存；重启板卡后恢复 |
| 加载后没有画面 | HDMI OUT、输入源、时钟锁定、使能和 HPD | 用已验证测试图/显示包排除显示链路问题 |

任何一次超时都应保留配置、硬件哈希、输入大小、错误类型及 TX/RX 状态。重试只在确认复位成功且输入契约已经修正后进行，避免反复对同一错误无限重试。板卡网络账户和访问地址不放入配置或公开日志。
